# 舵机供电与首次测试

当前状态：仅 IMU 已通过 ESP32 真机读取，舵机电源未测量、ESP32 舵机通信未验证。

## 供电结论

不要把两只 HD-1910-C001 的电源经过 ESP32 的 3V3／5V 引脚或面包板来供给。3V3 电压不足；该开发板的 USB、保护器件、走线和引脚可用电流未核实，不能把 5V 引脚当作双舵机电源输出。

[飞特官方产品页](https://www.feetechrc.com/510257)列出 HD-1910-C001 工作电压 4–8.4 V，单只堵转电流 1.2 A（4.8 V 条件）。两只在该条件下堵转电流可合计约 2.4 A；不能把空载电流作为电源容量依据，也不能将该数值直接外推到其他电压。

已有记录曾显示 12.4 V 和过压／欠压状态，超过此型号标称上限。在确认实际舵机端电压前，不继续上电动作测试。

华为“66W”标称功率不等于当前输出电压或可用电流。需要具体充电头型号、输出铭牌、线材／诱骗模块及实测电压；不能凭“快充头”判断兼容，也不要将 9V／12V 直接接入舵机。

## 推荐连接拓扑

```text
电脑 USB ── ESP32-S3 COM 口 ── 3V3/GND ── BMI270
                    │
                    ├── UART 信号 ── 半双工 TTL 适配器 ── 舵机数据 D
                    └── GND ─────── 适配器 GND ───────── 舵机 G

符合舵机规格的独立稳压电源 ── 合适的供电端子与线材 ── 舵机 V/G
```

电源与 ESP32 共地。舵机电流走独立供电线路；杜邦线仅用作低电流信号／参考地连接。舵机头转杜邦线只改变接头，不完成半双工转换或稳压。

若用已有 Waveshare Bus Servo Adapter (A)，须按该板实际版本核对供电路径和舵机口 V 的实测电压；不能照板上 9–12.6 V 丝印给这款舵机选电源。参见 [微雪官方说明](https://www.waveshare.com/wiki/Bus_Servo_Adapter_%28A%29)。

## 首次测试顺序

1. 断开舵机，确认独立电源型号、输出额定电压／电流、极性；测量最终舵机接口的 V–G 电压。
2. 确认落在该型号允许范围内，电源及线路具有启动电流余量，再接一只舵机。不要通过故意堵转验证电源。
3. 配置适配器为 UART 控制并共地；确认当前已保存的舵机波特率。使用只读通信先检测 ID，再读取电压、温度、状态、当前位置。
4. 下部 ID 1、上部 ID 2 分别验证；通信成功不等于运动能力和电源容量已经验收。
5. 支撑结构、查清零位与方向，再做有界小角度低速动作，观察启动瞬间电压与是否掉线。

此文是下一阶段接入计划；本仓库尚无舵机运动固件，也没有完成舵机供电测试。
