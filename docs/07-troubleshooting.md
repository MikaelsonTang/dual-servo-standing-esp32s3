# 7 · 常见问题：先看现象，再动一处

[首页](../README.md) · [第一次运行](05-first-run.md)

## 软件打不开

| 现象 | 处理 |
| --- | --- |
| `.cmd` 一闪就没了 | 确认已全部解压；从目录打开终端运行该脚本查看报错 |
| 找不到 Python/py | 安装 Python 3.12/3.13，勾 Add to PATH，重新打开目录再跑 `00_setup.cmd` |
| 提示缺少 serial | 用本项目 `00_setup.cmd`，不要把包装到另一个 Python 环境 |
| 提示没有 tkinter | 使用 Python 官网带 Tcl/Tk 的 Windows 安装包 |
| 点击窗口入口没反应 | 终端运行 `.\.venv\Scripts\python.exe desktop\event_app.py` 查看错误 |
| 安装依赖很慢/网络错误 | 让组织者预装，检查网络后重试；不要下载来源不明的整合 EXE |

## USB / 串口

| 现象 | 处理 |
| --- | --- |
| 无 COM | 数据线是否只能充电，是否插 UART/COM 口，驱动是否正确 |
| Access denied/拒绝访问 | FD、串口监视器、活动窗口只能一个占同一串口 |
| 换电脑后原 COM 无效 | 用设备管理器重新识别，号码不固定 |
| 烧录成功但界面身份不匹配 | 确认 V21 固件与 V21 窗口在同一最新解压目录；窗口会直接拒绝其他版本 |
| 烧录后仍显示“14 秒”、固定零位 337/2872，且没有保存按钮 | 电脑运行的是旧窗口；关闭它，从最新 S3 V21 解压目录双击 `02_open_demo.cmd`。旧窗口若还显示“身份已核对”，板上固件也很可能是旧版，需用新目录的 `01_flash.cmd` 重刷并看见完成校验 |
| 程序启动日志乱码 | ROM 启动信息与应用波特率可能不同；应用端是 230400 |

## 读不到舵机或 IMU

| 现象 | 处理 |
| --- | --- |
| FD 读到、ESP32 读不到 | 改 ID 用 B/B；ESP32 控制用 A/A；核对 TX→17、RX→18、共地 |
| 只找到一颗 | 分别单接检查 ID，排除重号；看原装线是否松 |
| 两颗均无反馈 | 独立 5V 是否恢复，微雪电源正负是否接对，波特率是否都 1Mbps |
| 型号不匹配 | 原程序严格识别 HD1910 已验证的协议/固件字段；不要删掉校验硬跑其他型号 |
| IMU 灯亮但没角度 | 灯亮只说明供电，查 3V3、GND、SDA6、SCL7 和面包板导通关系 |
| 拔插换线后 IMU 异常 | 停止，断开 USB 和舵机电源，等灯熄灭再重连；带电拔插不是校准方法 |
| 0.0V/超时 | 先解决反馈，不能把 UI 的默认零当万用表实测 |

## 为什么“启动起身”是灰色

按顺序检查：已连接且身份匹配 → IMU 有效/零点就绪 → 两颗舵机反馈新鲜 → 两颗均卸力 → 本设备直立零位已保存 → 两轴各自处于所保存零位 ±48 计数 → 勾选“已扶稳机器人”。

运行/停止确认阶段变灰正常。机械直立但数字不匹配，见第 6 章；不要把机身摆歪去凑别人的零位。

## 运动时停了

| 提示/现象 | 意义与下一步 |
| --- | --- |
| 未跟上目标/跟踪误差过大 | 发送目标与实际位置差太大；查阻挡、线缆、供电与负载，不能继续堆目标 |
| 本次动作到时 | V21 起身没有固定总时限；局部小幅测试仍有独立限时。长时间无进展请人工停止，检查反馈和供电 |
| 回零时底座倾斜停止 | 尚未完成站稳确认就被再次放倒，或自行失稳；等整轮完成，不要见回正就立即翻倒 |
| 电压/温度/状态异常 | 检查外部 5V 带载压降、插头、降压容量与温升 |
| IMU 无效/数据过期 | 接线/通信/量程或振动等问题；保留日志再查，不取消数据保护 |
| 心跳超时 | 窗口/USB/电脑响应中断，程序停止；先恢复连接 |
| 上轴卡在约90° | 比较模型目标、发送目标和实际位置；可能是策略输出停滞，也可能舵机跟不上，不能一律加10° |

## 怎么把记录交给组织者

1. 停止并确认卸力后正常关闭窗口。
2. 在 `desktop/recordings/` 找到出问题时间的 `.csv`、`.jsonl`、`.json`。
3. 说明倾倒方向、有没有手扶帮助、在哪个阶段停、实际看到什么，附相应文件。
4. 只看到模型目标不能证明实物已经到位；只看到一轮成功也不能证明重复稳定性。

## 展示界面只有一版

本活动包仅使用 `02_open_demo.cmd` 打开最新“自起身实验室”。详细数据保留在CSV/JSONL中，排查时交给组织者，无需切换旧窗口。
