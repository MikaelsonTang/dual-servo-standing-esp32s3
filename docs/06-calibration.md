# 6 · 新装机器：机械零位、方向和 IMU 必须核对

[首页](../README.md) · [返回首次运行](05-first-run.md)

这一章最容易被跳过。两套相同零件，装舵盘时错一齿、换舵机或把 IMU 转 90°，都可能导致同一程序动作不同。新手按下面检查，需改代码和安装矩阵时由活动组织者协助。

## 三种“零”不是一回事

| 名称 | 在哪里设置 | 代表什么 |
| --- | --- | --- |
| 舵机 **ID** | FD | 它是谁：上 ID1、下 ID2，与当前角度无关 |
| 关节机械零位 | 装配姿态 + 固件/电脑端的编码器常数 | 哪个实际位置代表机器人直立 |
| IMU 启动水平零点 | 连接/重启时静止采集，或校准按钮 | 当前底座水平姿态作为参考 |

点击“校准零点”只处理第三项，不会让舵机回正、改变编码器零位或修复装反的轴。

## 6.1 活动中使用已调好的套件

本套原机固件和电脑端使用：

| 关节 | 原机编码器零位 | 默认启动允许范围 |
| --- | --- | --- |
| 上 ID1 | 337 | 289～385 |
| 下 ID2 | 2872 | 2824～2920 |

保持扭矩关闭，轻轻摆到组织者标好的直立姿态，用 `03_read_joint_zero.cmd` 核对编码器。若实物确实直立但读数不在范围内，按下一节重新标定，不要为了凑数字把机器人摆歪。

不能在通电保持时强掰。若明显有阻力，停止检查机械装配。

## 6.2 自己新装：读出属于这台机器的零位

1. 确认已烧录本项目固件，ID 和接线正确，舵机独立电源已接。
2. 关闭活动窗口和 FD，释放 ESP32 COM。
3. 底座平放，把中间支架和顶部长杆摆成真实直立；稳定扶住，勿带动关节。
4. 双击 `03_read_joint_zero.cmd`，输入 ESP32 的 COM。
5. 工具验证固件身份，只读反馈并发送 STOP，等待两颗卸力后采 30 个样本，不启动运动。若采样时位置变化过大，会报错要求重测。
6. 看到 `Upper ID1: ... Lower ID2: ...`，记下这两个数，结果同时保存在本地 `local_joint_zero.json`。
7. 下面举例：假如你读到上 `350`、下 `2850`，那只是**你这台**的例子，不要直接照抄。

### 同步修改两处，然后重新编译

用 Arduino IDE 打开项目后，在 `firmware/policy_shadow/joint_limits.h` 找到：

```cpp
constexpr int ZERO[2]={337,2872}; // 顺序：上ID1、下ID2
```

按自己的读数改，例如：

```cpp
constexpr int ZERO[2]={350,2850};
```

再用记事本打开 `desktop/data.py`，查找并修改：

```python
JOINT_ZEROS = {1:350,2:2850}
```

**两处必须一致。** 保留 `COUNTS={1536,1080}` 与训练范围，不额外改变正负方向。按第 4 章 B 用 Arduino IDE 编译、上传自己的源码，再重新打开窗口。

改了源码不能再用 `01_flash.cmd` 覆盖回原机预编译固件；脚本也会检查原机零位是否已被更改。将自己的源码和电脑端一起复制成套保存。

### 舵盘装配与编码器边界

若当前轴位导致机械行程跨不合适的编码器边界，组织者应先调整卸力的舵盘安装/多圈位置方案，再读取直立基准。本版驱动使用**有符号多圈位置**，不是简单把所有值对 4096 取模；不要自行用 0 与 4095 当硬限位。

原机转动正方向对应编码器减少，上下轴都已验证。重新装反舵机时，改两个零位数字不能纠正反向，必须先让安装/方向与教程一致。范围扩大还需逐级检查机械干涉；本仓库固件上限不是已验证的机械无碰撞保证。

## 6.3 IMU 安装方向检查（只读姿态，不启动舵机）

两轴卸力扶好，底座平放后连接窗口，等待水平参考采集。**每次只倾斜整个底座**，不要只扳舵机关节。

站在双长槽侧面朝机器人，缓慢倾斜约 10～15°：

| 实物操作 | 窗口应该怎样变 |
| --- | --- |
| 抬高无长槽的后侧，让底座朝双槽侧前倾 | 前后倾角 Roll 为正，Pitch 接近 0 |
| 恢复平放 | 两角回到接近 0 |
| 抬高你的右手侧边缘（底座向左倾） | 左右倾角 Pitch 为负，Roll 接近 0 |
| 恢复平放 | 两角再次接近 0 |

若主变化轴互换、符号反了或严重串轴，先停在只读阶段。IMU 不能松动，也不能只靠反复点“校准”修复。

固件 `calibration_generated.h` 内的 `MOUNT_R` 是原机器从传感器坐标转换到底座坐标的安装矩阵，`GYRO_BIAS_DPS` 是原机零偏。**这些数不是所有 BMI270 模块通用的出厂值。**

原同款套件应使用组织者已验证并标记的安装方向。自制布局须由组织者重新采集水平、前倾、侧倾和静止数据，生成自己的安装旋转/零偏，编译后重复本节只读检查；这是独立硬件调校步骤，当前双击烧录工具不自动生成这些参数。不能承诺任意模块朝向直接刷原机二进制就能运动。

## 6.4 最后由组织者确认再做整机动作

活动包只提供最新展示UI，不再提供旧版调试窗口。组织者应先核对ID、机械行程、零位和只读姿态；需要关节级调试时使用经核实的专用流程，由组织者操作，不让新手在展示界面试探极限。

上述检查通过后才进入[第5章](05-first-run.md)的扶护起身。零位匹配不能证明全部极限位置无干涉。
