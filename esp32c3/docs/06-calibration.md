# 6 · V25：在窗口保存这台设备的直立关节零位

[C3 首页](../README.md) · [返回第一次起身](05-first-run.md)

**V24 曾固定使用上 ID1=337、下 ID2=2872。V25 已改成每台 C3 主动采集、保存和读回关节零位，不再要求新设备凑这两个数。仅为关节零位无需改源码或重新训练。**

## 三件事分清楚

| 名称 | 含义 | 在哪里操作 |
| --- | --- | --- |
| 舵机 ID | 它是谁，上 ID1、下 ID2 | FD 逐颗设置 |
| 关节直立零位 | 当前两个编码器整数代表实物真实直立 | V25 的“保存当前直立关节零位” |
| IMU 水平参考 | 当前平放底座作为姿态参考 | 每次上电静止采集；平放时“校准 IMU” |

“校准 IMU”不会修改关节零位。“重连 IMU”重新初始化传感器、保留本次水平参考，不会改关节零位或自动起身。

## 6.1 第一次保存（新设备必须做）

1. 安装并烧录 **V25**，关闭其他串口程序，打开本包的 V25 展示窗口。V24 固件与 V25 窗口不能代替这一步。
2. 舵机独立供电、微雪 A/A、TX4/RX5/共地、IMU 四根线均正常。底座平放、两轴直立并静止，等待 IMU 自检和水平校准完成。
3. 确认两颗舵机“已卸力”。让中间支架居中、顶部长杆真实竖直，稳定扶住，不强行扳动有扭矩的关节。
4. 新设备会提示“本设备未保存”，关节卡显示**原始编码器整数**。例如 4045、321 是测试示例，不是你应照抄的值；也不要用 +224°、−326°之类旧零位算出的角度代替原始读数。
5. 点击 **保存当前直立关节零位**，阅读并确认弹窗：底座平放、关节真实直立、已卸力。保持约 2 秒不动。
6. 固件只读取两颗舵机的稳定反馈，至少 20 组新鲜样本且持续约 1 秒；移动超过 8 计数、IMU 不水平/不静止、舵机有扭矩或反馈异常会拒绝保存。
7. 成功后看到 **本设备零位 ID1 … / ID2 …**。数值写入当前 C3 的 NVS，校验读回后才应用。保存过程不写舵机目标、不驱动关节。
8. 存储期间姿态滤波可能重新进入短暂静止获取状态；保持不动，等 IMU 有效。真实直立时两轴实际角度应接近 0°。
9. 关闭窗口，底座继续平放直立；断电重启后再次等待自检并连接，核对仍显示刚保存的两个整数。**V25 发布时没有连接实机，这一步真实存储验证需要在你的 C3 上完成。**
10. 再轻放倒、扶稳、勾选确认、点击“启动起身”。不要在放倒状态重新保存零位。

## 6.2 保存之后使用什么基准

- 启动位置检查：两轴相对**该设备已保存零位**各不超过 ±48 个编码器计数。
- 角度显示、训练模型的关节观测、目标位置编码、上轴 ±135° / 下轴 ±95°行程，以及站稳后回零，全部使用该设备保存的基准。
- 每帧记录包含两个零位、是否已保存及采样状态；回放依据当时记录，不拿旧设备的固定值重新解释。
- 正常重启会校验并加载 NVS；没有有效记录或记录损坏时，保持未标定、禁止起身，不偷偷使用 337/2872 启动。
- 换舵机、拆舵盘重装、改机械直立姿态，或更换 C3 后，需要重新主动保存；程序无法凭 ID1/ID2 判断机械安装是否改变。
- 同一台机器反复放倒起身，不需要每轮重新保存。不能每次自动把当前关节姿态当零位。
- 正常烧录脚本不主动清除 NVS；擦除整片 Flash、改变分区或存储失败后重新核对状态。

## 6.3 保存按钮灰色或失败

按钮不要求关节先符合旧的 337/2872，只要求已连接 V25、反馈新鲜、两颗卸力、IMU 已校准有效、底座接近水平。

| 提示 | 要做什么 |
| --- | --- |
| 正在采样 | 保持真实直立静止，不点击其他动作；Esc 可取消 |
| 底座不水平 / 不静止 / IMU 未就绪 | 真实平放，等待 IMU 有效；如参考错了，平放后“校准 IMU” |
| 舵机反馈或供电无效 | 查独立 5V、A/A、共地、TX4/RX5、ID 和线缆 |
| 关节在移动 | 卸力后重新摆直并扶稳，再保存 |
| 存储写入/校验失败 | 不启动，保留记录；检查 C3 存储和重启后的状态 |
| 记录越界 | 需要完整行程留在有符号范围内；先由组织者检查模式/装配，不能简单对 4096 取模 |

软件只能验证稳定与通信，不能替你看出支架是否真的竖直；这由操作者确认。轴的安装正负方向、机械干涉和 IMU 朝向也不能靠零位保存自动修复。

## 6.4 IMU 方向仍需单独核对

IMU 固定到底座。原机 `calibration_generated.h` 的 `MOUNT_R` 和 `GYRO_BIAS_DPS` 是原机安装/零偏标定，并非所有 BMI270 通用出厂值。

站在双长槽一侧面朝机器人，暂不启动动作，只缓慢改变**整个底座**：

| 操作 | 预期主要变化 |
| --- | --- |
| 后侧、无长槽边抬高 | Roll 前后角为正，Pitch 接近 0 |
| 恢复平放 | 回到接近 0 |
| 右手侧边缘抬高 | Pitch 左右角为负，Roll 接近 0 |
| 恢复平放 | 再回到接近 0 |

轴互换、方向相反或明显串轴时，保持只读，组织者重新采集安装矩阵/零偏，再按[第 4 章 B](04-flashing.md#build-source)编译。该步骤与关节零位保存不同。

## 6.5 仍在用 V24 的旧包

V24 没有窗口保存功能，确实固定使用 337/2872，需读取编码器、改 `joint_limits.h` 与 `desktop/data.py` 两处并编译。新装设备推荐升级成套的 V25 固件与窗口，按本章保存即可。`03_read_joint_zero.cmd` 在 V25 包中仍只是辅助只读测量，不会自动更新保存值。
