# 5 · 打开窗口，完成一次起身

[烧录](04-flashing.md) · [C3 首页](../README.md) · [零位与方向](06-calibration.md)

## 先在平放状态连接

1. 微雪两个跳线帽 A/A，TX→4、RX→5、GND 共地；IMU 四线核对。
2. 舵机独立稳压 5V 已接，电脑 USB 接 C3，关闭 FD。
3. 底座平放桌面、中间支架居中、顶部长杆直立，整机静止。新上电先等约 35～40 秒完整自检与水平校准。
4. 双击包内 `02_open_demo.cmd`。左上选择这台 C3 的 COM，点击 **连接设备**。
5. 标题应为 **HD1910 · C3 完整测试 · V24**，连接状态为“已连接 · 身份已核对”。先不要勾选扶护。
6. 检查前后/左右倾角接近 0°；两张关节卡有实际角度、电压和“已卸力”。电压一般约 5V，不能只凭板上亮灯判断舵机通信正常。

## 窗口里每项是什么

| 区域 | 作用 |
| --- | --- |
| 设备连接 / COM / 刷新 | 找 C3，不是找微雪 USB 串口 |
| 校准零点 | 底座平放静止时，重新平均 IMU 水平参考；不修改关节机械零位 |
| 重连 IMU | 卸力确认后重新初始化传感器，保留本次水平参考；恢复后手动启动 |
| 前后倾角、左右倾角 | 底座姿态，不是舵机角度 |
| 下关节 ID2、上关节 ID1 | 大字是计算目标，小字是实际角度/电压/扭矩；暂停时大字可能保留上次目标，不代表正在运动 |
| 已扶稳机器人 / 启动起身 | 每轮都需重新勾选，启动一次受限起身 |
| 红色停止 / Esc | 随时请求停止并卸力，继续扶住结构 |
| 底部推理耗时和记录数 | 计算时间，不是电机转速；连接后记录自动保存 |

## 第一次动作

**独立购买或重新装配的机器，先做[第 6 章](06-calibration.md)。** 原机编码器零位上 ID1=337、下 ID2=2872，允许启动误差各 ±48 计数。不能为了凑数字把原本竖直的结构摆歪。

1. 关节在真实直立零位附近，窗口确认两颗舵机都卸力。
2. 保持关节相对角度，将**底座连同整机**轻放倒，扶护并避开运动关节；线缆留松，不拉住结构。
3. **放倒后不要点“校准零点”或重插 USB。** 否则当前倒姿可能被误用为新的水平参考。
4. 勾选“已扶稳机器人”，点击“启动起身”。本版不自动检测放倒后启动。
5. 观察“起身 → 确认站稳 → 回零 → 卸力”。动作最多 14 秒；站稳后的回零是控制器阶段，不是另一个训练模型。
6. 需要中断时按 Esc / 红色停止；确认已卸力后再移动关节。下一轮重新检查、放倒、勾选、启动。

出现写入失败、跟踪误差、电压异常或 IMU 无效时，先看[故障章](07-troubleshooting.md)，不要连续点击启动来掩盖同一故障。

## 记录在哪里

本包目录的 `desktop/recordings/` 自动生成时间戳 CSV 和 JSONL。CSV 可用 Excel 打开；JSONL 保存原始数据、指令和会话元数据。停止动作不会自动删除记录；断开窗口会关闭并保存文件。

连接重开、系统重启是不同事情：重连窗口不会自动重新采 IMU 零点；重新上电会。每次启动流程都先在平放状态核对姿态和关节反馈。
