# 7 · 出现问题按症状查

[C3 首页](../README.md) · [接线表](03-wiring.md) · [烧录](04-flashing.md)

## C3 不出 COM / 无法烧录 / 窗口无数据

按本次 SuperMini **元件面朝上、USB-C 朝上**的方向：

1. 拔掉 C3 的 USB。
2. 按住**左边 BOOT**，同时插回 USB。
3. 插好后等约 **2 秒**，再松开 BOOT。
4. 在设备管理器检查新 COM，按[烧录章](04-flashing.md)重新烧录。
5. 成功后轻按**右边 RST**一次，平放静止等待完整启动，再开窗口连接运行模式的 COM。

如果只是要退出下载模式，已烧录固件正常时可轻按 RST；BOOT 模式本身不是机器人数据程序。仍无设备时核对数据线、USB 口、插头和板型。不要同时开多个串口程序。

| 症状或提示 | 意思和下一步 |
| --- | --- |
| 串口被占用 / Access denied | 关闭 FD、Arduino 串口监视器、另一份展示窗口 |
| 已打开端口，身份未核对 | 等启动自检约 35～40 秒；核对 C3 V24 固件与配套 UI、230400；不是微雪的 USB COM |
| 小窗口一闪而过 | 先安装 Python 和 `00_setup.cmd`，不要直接在 ZIP 内运行；检查 Tcl/Tk |
| 只亮电源灯，舵机没读数 | USB 仅给 C3/IMU 供电；查舵机独立 5V、A/A、TX4/RX5、共地、ID、原装线 |
| IMU 无效 / I²C 扫描无设备 | 查 SDA6、SCL7、3V、G、面包板同组孔；线插稳；卸力后用“重连 IMU”并保持静止 |
| 一动 IMU 就失效 | 保存记录，区分 I²C 错误、采样过期、饱和和控制周期超时；不能只因电源灯亮就排除接触/供电问题 |
| 计算或程序周期超时 | 用 C3 V24，旧浮点网络曾在 C3 超过 20ms；不要烧 S3 固件或自己放宽实时门槛 |
| 校准一直没结束 | 底座平放、整机静止，不碰线；震动或传感器失效会清空静止采样窗口 |
| 启动按钮灰色 | 未勾选扶护、IMU/零点未就绪、关节偏离零位、舵机反馈不新鲜、未确认卸力；先看下方文字 |
| 放倒后完全没动作 | 需要手动勾选并启动；底座必须随整机倾倒，不能只转动上方支架 |
| 写入或应答失败 | 参数写入被检查拒绝，或舵机未有效应答；V24 已修复 V23 的底层旧上限，先核对标题和固件，不把它当作烧录失败 |
| 实测位置越界 / 跟踪误差过大 | 实测角度偏离软件允许范围或发送目标；检查机械、零位、方向、供电，不反复增加角度掩盖问题 |
| 供电/温度异常 | 此包要求舵机反馈 4.0～5.5V、温度低于 50℃，检查稳压输出、线径、端子、负载和压降 |
| 动一下然后 14 秒到时卸力 | 整轮超时，不一定碰了 90°限位；保留 CSV，看方向分支、目标/实测、姿态，V24 已补齐约 4°～6.9°侧偏的路由空档 |
| 站起来但没回原位 | 核对是否达到站稳判据、是否因错误/超时提前卸力、机械零位是否正确；不是简单追加固定回位角 |
| 重连后角度仍很歪 | 重连保留水平参考，不会重新校准；只有底座确实平放静止时才点“校准零点” |

若问题重复，保留 `desktop/recordings/` 中对应 CSV/JSONL 和停止文字，记录方向、动作、是否手扶、供电情况。先停止并确认卸力，再处理接线或姿态。
