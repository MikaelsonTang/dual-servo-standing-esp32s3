# C3 教程图片来源

- `c3-pinout.svg`：按本次 ESP32-C3 SuperMini 正面实物和已验证接线绘制。不是 PCB 工程图，其他板型以丝印为准。
- `c3-wiring.svg`：本项目绘制的功能接线示意，线条颜色不代表原装导线颜色。
- `c3-supermini-photo.jpg`：项目提供的本次 C3 实物照片，未修改；USB-C 朝上时左 BOOT、右 RST。
- `adapter-ports.webp`：微雪官方 [Bus Servo Adapter (A) 接口说明](https://docs.waveshare.net/Bus_Servo_Adapter_A/)。
- `adapter-mode-a.webp`、`adapter-mode-b.webp`：微雪官方 [UART / USB 接线示例](https://docs.waveshare.net/Bus_Servo_Adapter_A/Product-Wiring-Example/)。图片中的电源文字不代表本项目输入要求，本项目仍为稳压 5V。
- `fd-search.png`、`fd-program.png`：FD 1.9.8.3 未连接软件界面截图，复用仓库原教学图片；用于辨认控件，不是本轮实机连接证据。
- `assembly.png`、`assembly_roles.svg`、`breadboard.svg`：原项目装配参考和结构/面包板教学示意，电路板接线以 C3 专用表格为准。
